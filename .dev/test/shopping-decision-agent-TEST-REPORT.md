# 测试报告: 购物决策代理 Agent

日期: 2026-08-09

## 1. 测试环境

- macOS, Python 3, Playwright Chromium
- LLM: 本地 Qwen3.5-2B (mlx_vlm) 优先 + Qwen API (qwen-turbo) 兜底
- 登录态: data/cookies.json (京东 116 cookies, 天猫 95 cookies)

## 2. 测试场景

| # | 场景 | 输入 | 结果 |
|---|------|------|------|
| 1 | 人体工学椅 | "人体工学椅 腰椎间盘突出 家里办公打游戏 预算1000" | ✅ 通过 |
| 2 | 路由器 | "路由器 120平米全屋覆盖 预算300" | ✅ 通过 |
| 3 | 相亲伴手礼 | "相亲伴手礼 预算500" | ✅ 通过 |

## 3. 核心链路验证

### 3.1 需求解析 (意图解析)
- 输入自然语言 → 输出搜索关键词、关键参数、预算区间
- 本地模型 3.3s/次，API 兜底正常

### 3.2 商品搜索
- 京东: 搜索 → 新版 DOM 适配 (data-sku, doubleCardWrapperAdapt) → 20 个商品
- 天猫: 搜索 → 新版 DOM 适配 → 20 个商品
- 预算过滤: 按预算上限 × 1.2 容差过滤

### 3.3 详情参数采集
- Top 5 商品，随机延迟 2-4s 防频控
- 参数表 (title+desc 键值对)、品牌、价格、累计评价数
- 部分品类无速览参数区时标注"未获取"

### 3.4 LLM 对比推荐
- 标题精确匹配防 index 错位
- 输出 Top 3 推荐 + 推荐理由 + 注意事项

### 3.5 自动下单
- 京东: 选规格 → 加购 (#add-to-cart) → 结算 → 提交 (.payment-action-submit) → 跳转 payc.m.jd.com/d/cashier/ ✅
- 天猫: 选规格 (过滤广告项) → 加购 → 购物车勾选 (.ant-checkbox) → 结算 (div.btn--QDjHtErD) → 提交 (真实鼠标点击 [class*=trade-buy-btn-submit]) → 跳转 cashiersa128.alipay.com ✅

## 4. 边界条件

| 条件 | 处理方式 | 结果 |
|------|---------|------|
| Cookie 过期 | login.py 扫码重新获取 | ✅ |
| 商品规格售罄 | 选规格失败时抛异常，需换商品重试 | ✅ |
| 频控触发 | 随机延迟 + 频控检测重试 | ✅ |
| 非交互模式 (管道输入) | EOFError 捕获，读取管道选择编号 | ✅ |
| 无速览参数品类 | 标注"未获取"，LLM 不编造 | ✅ |

## 5. 已知限制

- 评价内容受平台反爬限制，仅采集"累计评价数"
- 平台 DOM 改版可能导致选择器失效，需维护
- 本地 LLM 需在有 Metal GPU 的桌面会话启动

## 6. 结论

核心链路 (搜索 → 详情 → 对比 → 下单 → 支付页) 全部实测通过，3 个场景泛化验证通过，可以投入使用。
