# 变更记录

## v0.1.0 - 2026-08-07

首个可用版本，完成购物决策核心链路。

### 新增

- 自然语言意图解析（Qwen LLM，本地模型优先 + API 兜底）
- 京东 / 天猫双平台搜索（新版 DOM 适配）
- 商品详情参数采集（参数表、品牌、价格、累计评价数）
- LLM 场景化对比推荐（Top 3 + 推荐理由，标题匹配防错位）
- 一键启动脚本 `start.sh` + README
- 登录 Cookie 持久化（`login.py`，扫码一次后续复用）

### 修复

- 平台频控：详情采集降为 Top 5 + 随机延迟 + 频控检测重试
- 推荐 index 错位：改用商品标题精确匹配
- 品牌缺失：从商品标题提取品牌
- 非交互模式 EOFError：stdin 非 TTY 时跳过下单提示
- 本地 LLM 返回类型：`GenerationResult.text` 提取
- Qwen API `.env` 路径：改为从项目根目录或 `backend/.env` 读取

### 已知限制

- 评价内容受平台反爬限制，仅采集"累计评价数"
- 部分品类（杯子/梳子等）京东详情页无速览参数区，参数表缺失
- 本地 LLM 需在有 Metal GPU 的桌面会话启动
